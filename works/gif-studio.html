PROJECT 04 — VIDEO → GIF

GIF Studio Pro GIF STUDIO

拖一段视频进来，选起止、帧率和宽度，导出 GIF；不用另外装 ffmpeg。

年份
2026
技术
Python · moviepy · ffmpeg
状态
已打包 exe
仓库
未公开

它做什么

拖放或选择视频，预览画面，拖动时间轴选一段，设帧率、宽度，点导出。生成的是带调色板的 GIF，比直接截帧小很多，颜色也更稳。

深色界面，参数一次填完就能跑；导出过程有进度，不会假装在动。

怎么做的

核心是 moviepy，ffmpeg 随程序一起打包，用户不需要配环境。导出分两步：先把选中的片段转成临时 mp4，再用 palettegen 生成调色板、paletteuse 套回去。两遍比一遍慢一点，但边缘和渐变干净得多。

界面在 gui/ 里拆成主题、日志、视频加载、导出、拖放几个模块，导出跑在后台线程，主界面不卡。

动图是最小的视频，也是最难压的视频。

踩过的坑

  • PyInstaller 打包后，ffmpeg 的路径会变，必须用运行时路径去找，不能写死。
  • 长视频全读进内存会炸，只能按片段读。
  • 帧率越高越顺，但文件大得很快；默认值和提示都要保守。
  • GIF 只有 256 色，肤色和天空最容易出现色带，调色板策略比参数更重要。

导出失败时保留临时文件，方便下一次直接重试，不用重新解码一遍。
